# My E-Commerce Store

A beginner-friendly e-commerce demo built with HTML, CSS, and JavaScript.

## Files
- `index.html` — page structure and products
- `style.css` — page styling
- `script.js` — add-to-cart counter, total, and demo checkout

## Run
Open `index.html` in your web browser.

This is a learning demo only. It does not process real payments or save orders.
